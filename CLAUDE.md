# Project guidance

Read [AGENTS.md](AGENTS.md) and [README.md](README.md). The same scope,
verification, source-fidelity, and non-deletion rules apply to every assistant.
This repository does not require a particular AI tool or model.

Publication rule (user instructions, 26 and 30 September 2026): **Goodman
and Applications/2.11 are the only applications authorized for public
inclusion. All other applications remain local.** Follow
AGENTS.md's public application boundary before every commit, push, release
or pull request, including checks of shared documentation and artifacts.
A general request to publish the repo does not override this restriction.
