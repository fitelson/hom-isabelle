# Bacon's full-type Classicism

The source full-type calculus is book_full_C_proves (H+MF+PE). The older
book_C_proves is a distinct Equivalence-rule base. The representation and
modal_semantics subdirectories develop the canonical model, the independent
model class, generic full-C soundness, and modal completeness: derivability
from a theory iff root consequence over the nontrivial class, under the
declared-name smallness hypothesis
(`modal_semantics/soundness/Bacon_Book_ZF_Full_C_Declared_Names_Completeness.thy`).
Signatures whose declared-name union has no injection bounded by a ZF set
are outside that construction.
